# Learning log

- 2026-10-18: Local Codex CLI is 0.155.0-alpha.16 and supports `codex exec --json --sandbox`; Claude CLI is absent locally, so its adapter is implemented from official CLI documentation and needs live validation.
- 2026-10-18: On this macOS setup, Python skipped a `uv` editable-install `.pth` file with the filesystem `hidden` flag. Clearing that flag restored `adp` imports. The packaged wheel includes all role profiles and avoids that editable-install dependency.
- 2026-10-18: The real threat-model verifier accepted a generated schema-version-2 fixture through the adapter; a syntactically valid fixture does not establish a secure design.
- 2026-10-18: Keep conversational backlog planning in one repo-scoped Codex skill. A GitHub issue edit to an unmerged ticket triggers control-plane replanning, and `project_id` filters out new issues until they join the configured Project.
- 2026-10-18: Safe stop uses a fenced worker yield: unfinished jobs return to the queue at the same revision, while completed stages and issue worktrees supply durable resume points. Yielded jobs retain worker affinity because partial files are host-local; abrupt loss relies on lease expiry and manual affinity release is available for permanent host loss.
- 2026-10-18: Local startup is a manual, one-command script that reuses the Compose PostgreSQL volume, preserves a saved pause by default, and runs the host worker in the foreground. Explicit `--resume` is required to clear a global pause; hybrid workers can use `--worker-only` without local Docker.
- 2026-10-18: Worker subprocesses now receive purpose-specific environment variables, and local startup drops the administrator token before worker launch. Git hooks are disabled for worker Git calls, and GitHub API tokens are reserved for `gh`, not Git commands. Environment filtering does not isolate same-user credential files; a confined worker host remains necessary.
- 2026-10-18: The macOS staging PostgreSQL backup restored in a separate database with exact core-table row comparisons while dispatch and the scheduler were paused. macOS `mktemp` needs the random `X` characters at the end of its template. Local mode-0700 backup storage supports accidental-loss recovery but remains vulnerable to same-user compromise or host loss, so an off-host protected copy is still required.
- 2026-10-18: A macOS launchd job could not enter this checkout under `Documents` because of privacy controls. Scheduled backup and restore scripts are copied under `~/.local/share/blueprint-gate/bin` and address the named local PostgreSQL container directly.
- 2026-10-18: Job heartbeat, yield, and completion must lock the job row and reject an expired lease; a token match alone is insufficient before reclaim. Remote Git/GitHub commands must remain cancellable so periodic claim checks can stop their process group. These checks cannot undo a remote effect that finishes during claim loss, so publication reconciliation remains a separate requirement.
- 2026-10-18: GitHub signs the webhook body, not the delivery or event headers. Store a unique payload digest as well as the delivery ID before reconciliation, and check the claimed event against the signed body shape. A bounded previous-secret interval allows an ordinary secret change without disabling signature verification; suspected secret compromise calls for direct cutover.
